# Legacy Migration Inventory

The existing `EnshroudedModHub` repository remains a reference source. It is
not the new UI foundation.

## Migrate as knowledge and evidence

- Capability audits.
- Runtime research notes.
- Compatibility findings.
- Safety and recovery policy.
- SDK contracts.
- Probe designs and evidence indexes.
- Build-specific limitations.

## Review before migrating as implementation

- Game and build detection.
- Profile formats.
- Installer ownership and staging.
- Backup and restore services.
- Health reporting.
- Compatibility services.
- Research preflight and evidence cataloging.

## Do not copy directly

- Legacy GUI layout.
- Legacy wizard flows.
- UI-specific orchestration.
- Hard-coded machine paths.
- Unverified feature claims.
- Experimental runtime code without current evidence.
